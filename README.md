# 快享盒 Android 更新

本仓库仅提供 APK、版本说明和更新清单，应用源码保持私有。

## 下载

前往[最新版本](https://github.com/code-mm/android-app-kxh-releases/releases/latest)下载安装。当前版本为 **1.2.0**，声明支持 Android 6.0（API 23）及以上；本轮实机环境验收为 Android 10 专用模拟器。

1.2.0 采用全新绿色界面，统一服务发现、手动连接、文件浏览、下载和设置体验，并修复系统导航键及旋转后的浏览状态恢复。

## 应用内更新

每次打开自动检查正式版本，有新版本时可选择稍后或下载安装。新版也可进入「设置 → 检查更新」；1.1.1 的手动入口仍在发现页。

旧版 1.0.0 没有更新检查功能，需要手动覆盖安装一次最新版，之后即可使用应用内更新。沿用同一签名，覆盖安装保留数据。首次安装更新时，Android 可能要求允许快享盒安装此来源的应用。

无网络或 GitHub 暂不可用时，局域网共享功能仍可使用。下载后会核对包名、真实版本、大小、SHA-256 和签名，再交由 Android 确认安装。
